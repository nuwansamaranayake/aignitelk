# Truth layer: technical SEO pass, 2026-10-08

Scope: robots.txt, real 404s, homepage heading and canonical, one Organization entity
across pages, breadcrumbs. No new claims. No visible copy changed except the 404 page.

## 1. Diagnosis

- Every unknown path, plus /robots.txt and /llms.txt, returned 200 with the homepage.
  nginx fell back to /index.html. The site is a static export, so no real route needs that fallback.
- The homepage H1 was the award line. The line that says what the company does was an H2.
- Three company names in markup: "AiGNITE Software (Pvt) Ltd" (homepage),
  "AIgnite Software (Private) Limited" (product pages), "AiGNITE Sri Lanka" (GoviHub).
- www served a duplicate site. The Traefik www redirect router never wins (see the SEO report).
